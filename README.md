## Main Focus

These are the projects I spend most of my time on:

| Project | What it is | Why it exists |
| :--- | :--- | :--- |
| **[SwiftDisc](https://github.com/M1tsumi/SwiftDisc)** | A lightweight, native Swift library for building Discord bots on iOS and macOS. | Swift needed a proper, no-nonsense Discord wrapper. This is it. |
| **[Arena-b](https://github.com/M1tsumi/arena-b)** | A fast, practical bump allocator for Rust. Ideal for parsers, game engines, or temporary object batches. | `malloc` isn't always the right tool. Sometimes you just need to allocate fast and free it all at once. |
| **[VelocityX](https://github.com/M1tsumi/VelocityX)** | Lock-free data structures for Rust (MPMC queues, hashmaps, work-stealing deques) with deep documentation. | Fast concurrent structures should be understandable, not just fast. |
