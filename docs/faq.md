# FAQ

- **Is SwiftDisc production ready?**
  Early stage; APIs may change. Pin versions and watch releases.

- **Do I need privileged intents?**
  Only if you need member/message content features. Configure in the Developer Portal.

- **Which platforms are supported?**
  Apple platforms and Windows (where Foundation networking supports WebSocket). See [Windows Notes](./windows.md).

- **Where to ask for help?**
  Join the Discord server or open an issue.
